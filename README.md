## 📌 Sobre o Repositório

Este repositório foi criado para organizar o código sobre o assunto inversão de controle e injeção de dependência usando Java e Spring boot

O objetivo principal é documentar:
* 💡 Como ocorre a inversão de controle e injeção de dependência usando a linguagem Java e o ecossistema Spring.
* 🎯 Quando usamos a anotação @Autowired injetamos a dependência através do framework Spring. Podemos fazer isso também através do construtor. 
* 💻 Registrando os componentes com @Service, @Component, @Entity conseguimos mostrar ao Spring o que deve ser registrado como Bean, e daí em diante o Spring faz o monitoramento de todo o ciclo do componente.
